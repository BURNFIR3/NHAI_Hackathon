# Future Improvements

This project already supports a strong Android offline facial authentication path. The next evolution should emphasize cross-platform expansion and secure sync.

## Planned enhancements

- Add AWS syncing for face templates, audit logs, and device enrollment state.
- Add iOS support with native platform channel integration and on-device ARM64 inference.
- Support secure backup to AWS S3 with encryption and versioned template storage.
- Add automatic model update delivery so new YuNet / MiniFASNet / EdgeFace variants can be downloaded safely.
- Improve user experience with adaptive image quality guidance and faster cold-start model load times.
- Add OTA configuration for liveness thresholds, recognition tolerance, and privacy policy updates.
